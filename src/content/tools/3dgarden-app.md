## Overview

[3D Garden](https://3dgarden.app/) is shared publicly as a place to explore handmade, low-poly 3D models for Three.js projects. Community posts describe a model library and advertise more than 800 free models. Those are **third-party/promotional claims**, not features or totals independently confirmed by this catalog.

## Verification and usage boundaries

The provided domain could not be inspected directly during this review. Treat availability, downloads, supported 3D formats, account requirements, model licenses, attribution rules and commercial reuse as **unverified** until the official website can be reviewed. A model being described as free does not automatically grant unrestricted redistribution.

This listing is for **3dgarden.app** specifically. The similarly named open-source project [ThreeD Garden](https://github.com/marty-mcgee/threed-garden), associated with **threedgarden.com**, has not been established as the same service.
