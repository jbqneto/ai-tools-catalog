## Overview

This repository packages coding-agent practices for the software-development lifecycle. It includes workflows such as `/spec`, `/plan`, `/build`, `/test`, `/review`, and `/ship` that aim to keep coding agents aligned with quality and verification steps.

**Typical uses:** planning complex changes, test-driven workflows, reviewing code, and standardizing development steps across repositories.

**Limitations:** Agent skills are **process guidance**, not substitutes for execution safeguards, code review, and tests. Some integrations use client-specific slash commands; shared reference documents may not be included when installing only one individual skill.

**Source:** [Official project repository](https://github.com/addyosmani/agent-skills).
