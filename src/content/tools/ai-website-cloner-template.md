## Overview

AI Website Cloner Template is a **project scaffold and agent-assisted implementation workflow**, not a hosted site-cloning API. An AI coding agent inspects a reference website, maps its routes and visual states, extracts permitted assets, and rebuilds an editable Next.js application. The documentation includes a `/clone-website` workflow.

## Useful for

- Rebuilding **your own** websites or authorized legacy UIs.
- Investigating responsive layouts and frontend structures.
- Creating a maintainable starting point for migrations and redesigns.

## Licensing and limitations

The template uses **MIT** licensing. The documented setup requires **Node.js 24+** and a compatible coding agent; agent/model services may cost money.

**Permission matters:** do not copy private sites, third-party code, brand assets, fonts, or visual designs without appropriate authorization or rights. A generated implementation requires manual testing of responsiveness, accessibility, behavior, and security.
