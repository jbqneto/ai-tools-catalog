## Overview

This repository supplies a Next.js starter and a **/clone-website** workflow that asks a coding agent with browser access to inspect a website and recreate its interface in editable React/Next.js code. Its documentation describes support for Claude Code, Codex, Cursor, and OpenCode.

**Typical uses:** authorized website migrations, rebuilding an owned site, UI studies, and generating a starting point for new components.

**Limitations:** It is a starter and workflow, not a one-click service that guarantees accurate cloning. The documented setup requires Node.js 24+ and a separate coding agent. Only recreate websites and assets you own or are authorized to reproduce; inspect copyright, branding, and third-party components.
