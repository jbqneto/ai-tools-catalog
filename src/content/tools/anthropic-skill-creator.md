Skill Creator is included in Anthropic's official skills repository. It provides a structured approach to writing skills, developing evaluation prompts, comparing results, and iterating on skill instructions.

**Useful for:** designing custom agent workflows that can be reused and evaluated over time.

**Considerations:** publishing a skill does not guarantee reliability or safety. Agent skills that invoke scripts or external tools require independent permission and security review. Not every skill-evaluation feature is supported in every environment.
