## Overview

Skill Creator provides a structured workflow for drafting a skill, testing it against representative tasks, reviewing outputs, and refining instructions and trigger behavior. It is a *general skill-authoring tool*, not a video editor by itself.

**Use cases:** building project-specific skills, improving agent reliability, and creating reusable video-production instructions.

**Caveats:** inspect any scripts and permissions included in a generated skill. Evaluation requires meaningful test cases; passing a few examples does not establish universal reliability. Review terms for the Anthropic-maintained skills repository and any third-party dependencies.
