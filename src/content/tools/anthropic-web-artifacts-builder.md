## Overview

This official skill is for complex **Claude HTML artifacts**, with documented React 18, TypeScript, Vite, Tailwind and shadcn/ui tooling. It is not the same as deploying a multi-user SaaS, nor is it a new AI model. Use it for rich prototypes with explicit local review.
