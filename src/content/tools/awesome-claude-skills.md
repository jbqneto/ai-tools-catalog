## What it does

[Awesome Claude Skills](https://awesomeclaude.ai/awesome-claude-skills) is a browsable directory based on the community collection maintained by [BehiSecc](https://github.com/BehiSecc/awesome-claude-skills). It groups reusable skills and related references into topics such as development, document processing, data analysis, research, content creation, and automation.

A skill generally consists of instructions in a `SKILL.md` file and may include scripts or additional resources.

## Useful for

- Discovering task-specific Claude skills and related reference material.
- Learning common conventions for reusable agent instructions.
- Finding community-maintained examples for development and content workflows.

## Limitations

An **awesome list is a reference directory**, not an installation or security-verification service. Skills may be hosted in separate third-party repositories with their own licenses and maintenance practices. Inspect the original skill source and any scripts before adding it to an agent.

The directory content, link status, and the number of indexed skills can change over time.
