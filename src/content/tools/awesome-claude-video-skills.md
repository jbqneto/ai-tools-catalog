## Overview

[Awesome Claude Video Skills](https://github.com/zhuyansen/awesome-claude-video-skills) catalogues software and agent skills for creating and editing video using code-capable assistants. It covers rendering frameworks, promotional content, explainers, editing, Shorts, animation, motion graphics and related workflows.
