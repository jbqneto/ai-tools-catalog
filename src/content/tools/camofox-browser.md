## What it does

Camofox Browser provides a browser automation server built around **Camoufox**, a Firefox-derived browser with fingerprint-control features. Its documented integrations allow agents to create tabs, navigate, click, type, capture screenshots, and retrieve page content. It also exposes tools for agent-oriented workflows.

## Useful for

- Browser navigation and interaction by AI agents.
- Inspecting page content and capturing screenshots in automated workflows.
- Evaluating browser automation alternatives alongside Playwright and other tools.
