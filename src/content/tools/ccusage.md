## What it does

[ccusage](https://ccusage.com/) reads local usage data generated by supported coding-agent CLIs and summarizes tokens and estimated costs by day, week, month, or session. The tool began with Claude Code support and has expanded to additional coding assistants, including Codex and OpenCode.

Its reports can help compare local usage patterns across supported tools. The project documents a no-install quick start:

```bash
npx ccusage@latest
```

## Useful for

- Tracking tokens and approximate API-equivalent consumption across sessions.
- Comparing usage trends across supported developer agents.
- Exporting reports for personal analysis and budgeting.
- Identifying unusually expensive sessions or workflows.

## Limitations

Usage and cost calculations are **estimates based on local logs and pricing reference data**, not statements of amounts billed. Subscription usage limits, discounts, caching rules, and actual invoices can differ. The project does not collect usage from services that have no supported local logs.

Consult the [official documentation](https://ccusage.com/guide/) and [repository](https://github.com/ccusage/ccusage) for supported clients, requirements, and license terms.
