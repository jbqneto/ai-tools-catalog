## What it does

Claude Ads is an independent, open-source skill for **Claude Code** aimed at paid-media workflows. According to its maintainers, it supports analysis spanning **12 advertising platforms**, including Google, Meta, YouTube, LinkedIn, TikTok, Microsoft, Apple, Amazon, Reddit, Pinterest, Snapchat, and X.

The repository documents command-driven workflows for audits, reports, campaign planning, creative briefs, monitoring, and draft optimization suggestions.

## Useful for

- Reviewing advertising campaign exports and identifying evidence-backed issues.
- Preparing structured paid-media reports and action plans.
- Drafting creative briefs and experimentation plans for human review.

## Licensing and limitations

The public repository declares an **MIT license**. It is not an official Anthropic product.

Reports depend on the accuracy, completeness, and date range of the input data. The project documentation describes account modifications as permission-controlled, and it does not autonomously change advertising accounts by default.

Do not paste secret API keys or access tokens into prompts. Check the project documentation before enabling account integrations or actions that affect paid campaigns.
