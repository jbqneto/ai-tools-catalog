## What it does

[Claude Code Marketplaces](https://www.claudemarketplace.net/) is an independently operated directory of Claude Code-related resources, including skills, plugins, MCP servers, and community marketplaces. Visitors can browse and search listings by category and other filters.

## Useful for

- Finding community-contributed Claude Code skills and plugins.
- Comparing available marketplaces and MCP integrations.
- Discovering tools for coding, testing, security, and productivity workflows.

## Limitations

This directory is **not an official Anthropic service**, and appearing in the directory does not mean an entry has been security-audited, approved, or verified to function as described. Marketplace counts and install numbers may change. Check each component's actual repository, license, maintainer, permissions, and last update before installing it.

The official homepage is linked above. No official open-source repository for the directory itself has been verified here.
