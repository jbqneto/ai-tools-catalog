## Overview

[Claude Video Watch](https://github.com/bradautomates/claude-video) is an agent skill that turns a permitted online video or local file into selected timestamped frames and a transcript for AI-assisted review. Its README documents use with Claude Code, Codex, and other compatible Agent Skills hosts.

**Use cases:** summarize tutorials with visual references, inspect video structure, collect research notes, and locate moments in footage.

**Considerations:** Caption quality, frame selection, and model interpretation can omit or misread details. Optional transcription backends can require additional setup or incur external API costs. Confirm rights and privacy handling for input files.

**Distinction:** The catalog's [Claude Watch](https://github.com/devinilabs/claude-watch) entry points to a different implementation; similar display names are not duplicates without matching canonical project identity.
