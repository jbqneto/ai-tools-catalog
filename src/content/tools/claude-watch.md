Claude Watch samples frames around scene changes and combines them with captions or speech transcription. The README describes analysis of opening hooks and optional export of notes into Obsidian.

**Useful for:** studying editing patterns, identifying visual transitions, and reviewing tutorial or promotional videos.

**Considerations:** the name is shared by different projects; this entry points to the linked repository only. Evaluate dependencies and possible API-key use before running third-party scripts.
