## Overview

[Dashboard Design Skill](https://github.com/abdiraimov-otabek/dashboard-design-skill) provides a design playbook for AI coding agents working on dashboards. It prioritizes meaningful information hierarchy, clearly labelled comparisons, visual restraint and verification from actual screenshots. Its references include web and SwiftUI patterns.

## Verification and limitations

The skill is not a substitute for validating source data, accessibility, responsive behavior or user goals. The project's README describes an optional author sign-off that users may disable. Its code and instructional content are published under the repository's MIT license.
