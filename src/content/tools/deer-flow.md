## Overview

DeerFlow organizes long-running agent workflows using sub-agents, skills, tools, memory, and sandboxes. Its current major release is a rewritten agent harness with broader task support beyond the original deep-research implementation.

**Typical uses:** extended research, structured reports, coding tasks, multi-step content production, and agent experiments.

**Limitations:** The **2.x** architecture is substantially different from the earlier **1.x** deep-research project. Successful autonomous execution depends on model access, configuration, search tooling, and sandbox security. Human verification remains essential for factual reports, external actions, and published material. See the [official site](https://deerflow.tech).

**Source:** [Official project repository](https://github.com/bytedance/deer-flow).
