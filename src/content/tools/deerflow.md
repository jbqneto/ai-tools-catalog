## Overview

DeerFlow is an open-source **agent harness** for longer-running workflows involving research, planning, coding, and report generation. The current 2.x project coordinates subagents and skills with memory and sandboxed execution.

## Useful for

- Multi-step research with agent-driven tool use.
- Experimenting with sandboxed execution and subagent delegation.
- Prototyping research and content-generation workflows.

## Licensing and limitations

**MIT**, according to the official repository. DeerFlow 2.x is a substantial rewrite of its original research framework; do not assume older 1.x tutorials are compatible. The README lists runtime and infrastructure prerequisites and configurable AI-model providers.

Autonomous research outputs require fact checking, citation review, and strict permissions for tools, secrets, and file operations. A long-running agent is **not** a guarantee of accurate, complete, or unattended results.
