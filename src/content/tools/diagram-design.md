## Overview

[Diagram Design](https://github.com/cathrynlavery/diagram-design) is an agent skill for generating diagrams as a self-contained HTML document with SVG elements. Its maintainers document numerous diagram formats, including architectural layouts, flow diagrams, sequence diagrams, and comparison charts.

The skill can work with agent tools that support reusable skill files. It can also help adapt diagram aesthetics to an existing brand.

## Common uses

- Draw software architecture diagrams for technical documentation.
- Produce system flows, timelines, comparison charts, and decision diagrams.
- Export or adapt SVG-based visuals for slides and documentation.

## Getting started

The project documents this installation method:

npx skills add cathrynlavery/diagram-design
