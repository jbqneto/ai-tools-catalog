## Overview

Expo Skills is a curated collection maintained by the Expo team for AI coding agents. It documents common Expo and React Native workflows, including project structure, native UI, routing, animations, EAS builds, and release management.

**Typical uses:** implementing Expo applications with coding agents, making SDK-compatible code changes, organizing mobile projects, and checking build or deployment workflows.

**Limitations:** Skills provide instructions and **do not independently build or publish apps**. Expo CLI, documentation, and EAS remain authoritative. Some EAS services and deployment workflows may have costs or plan limits beyond the open-source skills.

**Source:** [Official project repository](https://github.com/expo/skills).
