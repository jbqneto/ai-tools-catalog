## Overview

[Friction](https://github.com/friction2d/friction) is a desktop application for building vector and raster motion graphics. It is based on the earlier *enve* animation project and provides an alternative to proprietary motion-design software.

**Good fit:** editable 2D animations, logo motion, graphic sequences, and visual assets prepared for use in video or web projects.

**Trade-off:** It is a desktop editor, not a code-first generator or AI tool. Programmatic generation requires a separate integration strategy. The upstream project states that AI-generated code is not accepted directly as a contribution; maintainers require human rewriting.

**License:** GPL-3.0-only for the main program, with some third-party components under their own licenses. See the [official project documentation](https://friction.graphics/documentation).

**Source:** [Official source repository](https://github.com/friction2d/friction).
