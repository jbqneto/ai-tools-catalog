## Overview

GSAP Skills supplies official guidance for AI coding agents using GreenSock animation APIs. It covers timelines, tweens, ScrollTrigger, plugins, common JavaScript frameworks, performance, and animation troubleshooting.

**Typical uses:** generating production-oriented animations, maintaining consistent GSAP conventions, and helping agents integrate animation into React, Vue, Svelte, and plain JavaScript.

**Limitations:** This is a **separate agent-skill collection**, not the GSAP runtime library (which has its own catalog entry). Using the skills does not grant rights beyond the [GSAP standard license](https://gsap.com/standard-license/). Review package-specific dependencies and terms.

**Source:** [Official project repository](https://github.com/greensock/gsap-skills).
