## Overview

Herk Edit Kit, formerly HyperFrames Student Kit, combines skills for Claude Code and Codex with editing scripts, motion graphics, and example projects. It supports cutting silences, reviewing mistakes, short-form storytelling, captions, and HyperFrames-based visuals.

**Distinction:** HyperFrames itself is already listed as a rendering framework. Herk Edit Kit is a broader editing and production workflow built around multiple tools.
