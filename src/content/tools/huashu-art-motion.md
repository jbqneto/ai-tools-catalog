## Overview

[Huashu Art Motion](https://github.com/alchaincyf/huashu-art-motion) is a code-first animation skill. It describes how an agent can animate art-style scenes, design explainer sequences from structured JSON, break down a reference into cuts and beat grids, and render short films using browser-based tooling. The repository includes a long-scroll art-transition demo and quantitative quality checks.

## Licensing and production notes

Most working instructions are in Chinese; a shorter English overview is available. The README describes MIT-licensed code and documentation with **explicit exceptions** for character artwork, demo videos, fonts and certain derived stroke data. Do not assume those bundled visual assets are licensed for unrestricted reuse. The source contains runnable scripts and scene templates, rather than a full visual timeline editor.
