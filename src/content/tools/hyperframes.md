## Overview

HyperFrames treats video as a seekable HTML composition. Authors can combine HTML, CSS, GSAP, and other browser animation tools, then render deterministic frames with a browser and FFmpeg.

**Use cases:** kinetic typography, product promos, animated visualizations, and website-to-video experiments.

**Caveats:** rendering requires a browser and FFmpeg; compositions need reproducible, time-controlled motion. The project declares Apache-2.0 licensing. Review external media and fonts separately.
