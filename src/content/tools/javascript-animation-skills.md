## Overview

[JavaScript Animation Skills](https://github.com/iart-ai/javascript-animation-skills) provides an agent workflow for generating an HTML Canvas film where each frame is derived from time. Its companion soundtrack skill synthesizes music and effects through Web Audio. The renderer can produce an MP4 and inspection artifacts.

## Relationship to existing catalog entries

This is a separately installable skill pack from the broader [Motion Skills](https://github.com/iart-ai/motion-skills) ecosystem, which is already listed as a collection in this catalog. It is not a duplicate of that directory entry.

The upstream README specifies browser dependencies, FFmpeg and no required API keys for the local renderer. The repository declares an MIT license. Review the generated HTML, its visual consistency and audio rights before publishing.
