## Overview

MCP for Blender connects AI clients to Blender through a Model Context Protocol server and an add-on. Agents can perform supported scene-editing operations from natural-language instructions using explicit tools.

**Typical uses:** scripted 3D modeling, scene inspection, light and camera changes, and agent-assisted workflows that export assets or render scenes.

**Limitations:** This is a **third-party integration, not an official Blender feature**. The project renamed its package from `blender-mcp` to `mcp-for-blender`; old setup names may still appear. Local permissions and tool-execution scope should be reviewed carefully. A working Blender installation and compatible agent are required.
