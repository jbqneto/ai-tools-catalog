## Overview

The repository's `motion-broll` skill uses input video and a transcript to plan visual cutaways or transparent overlays, then generates motion-graphic clips aligned to specific spoken phrases. It provides review artifacts and timestamps for placing clips in an editor.

**Use cases:** talking-head videos, tutorial explanations, animated diagrams, and graphical overlays.

**Caveats:** the generated media still needs editorial placement and review. Dependencies include FFmpeg, a browser renderer, and the project's scripting tools. Do not treat generated notes as verified transcripts.
