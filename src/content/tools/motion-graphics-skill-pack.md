## Overview

[Motion Graphics Skill Pack](https://github.com/charlie947/motion-graphics-skills) is a community-maintained collection of skills aimed at generating motion graphics using coding agents. The upstream project describes a set of techniques for launch-oriented visuals, typography, and animation, with frames produced through code.

**Use cases:** kinetic typography, promotional animations, product demos, and repeatable motion-design patterns.

**Distinction:** This is **not** the same as [Motion Skills](https://github.com/iart-ai/motion-skills) or [Motion Graphics B-roll](https://github.com/Barty-Bart/motion-graphics), which are separate maintained projects. It is independently verified as a relevant project, not definitively attributed to the ambiguous “Motion Graphics” label in a social-media slide.

**Considerations:** Motion design still needs visual review, and rendering depends on local tools and installed skills. Review repository scripts and permissions before use.
