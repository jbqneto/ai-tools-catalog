## Overview

This project curates motion-production skills covering text animation, explainers, charts, branded videos, WebGL, Shorts, and more. Skills are offered in separately installable packs; agents use them as task-specific production guidance.

**Use cases:** repeatable animation standards, visual explainers, social media motion, and training coding agents to check rendered output.

**Caveats:** the number and names of packs evolve. These are instructions and scripts, not a substitute for render engines. The repository declares an MIT license; inspect each dependency and executable script.
