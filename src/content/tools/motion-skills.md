Motion Skills provides curated skills and packs for different motion-design use cases, including TikTok/Reels, talking-head overlays, animated charts, WebGL, explainer videos, and motion graphics.

**Useful for:** building reusable motion-animation workflows with coding agents and learning implementation techniques.

**Considerations:** each pack may have its own dependencies and may execute commands or access local files. Inspect the installed skill and project licenses before granting agent execution permissions. The number of available packs can change.
