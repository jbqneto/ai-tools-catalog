## Overview

Motion, formerly Framer Motion, provides animation APIs for web interfaces and applications. Its primary packages can be used without AI. The project also documents optional agent-facing documentation tools and a separate AI kit.

**Distinction:** Motion is the underlying library; independent coding-agent skills that teach Motion APIs are separate resources.

**Sources:** [Official project](https://motion.dev/) · [GitHub repository](https://github.com/motiondivision/motion).
