## Overview

[openGym](https://github.com/DuarteSantos8/openGym) is an independently developed workout and body-weight tracking application. It allows users to plan training sessions, record exercises and sets, track body weight, and review progress with statistics and visualizations.

The project supports self-hosting and offers an installable web experience. Consult the official documentation for supported deployments, authentication, and backup procedures.

## Common uses

- Keep a personal exercise log without depending on a hosted fitness subscription.
- Review training frequency and body-weight history.
- Run a private fitness tracker on infrastructure you control.
