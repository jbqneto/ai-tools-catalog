## What it does

[OpenChatCut](https://github.com/0xsline/OpenChatCut) is an independent, open-source video editor that combines a conventional multitrack timeline with an embedded AI agent and external agent integrations.

The project documents conversational editing of real timeline objects: cuts, captions, transitions, effects, audio tracks, and motion graphics. Projects remain editable after an agent changes them, and users can review or undo edits. It also describes connections to Claude Code and Codex through MCP tools.

## Useful for

- Editing video through natural-language instructions while retaining manual timeline control.
- Testing agent-assisted clipping, captions, transitions, and multimedia assembly.
- Building workflows where an AI agent makes inspectable, reversible edits instead of generating an uneditable final video.

## Licensing and limitations

The project's open-source code is licensed under **AGPL-3.0**. A separate **OpenChatCut Pro** offering is advertised on its official website; do not assume every commercial feature is part of the open edition.

Feature availability, export stability, computing requirements, and external API costs depend on the installation and current release. If using external AI providers, assess privacy and data-transfer behavior separately from the project's local-first design.

OpenChatCut describes itself as an independent alternative to ChatCut; it is not affiliated with the commercial ChatCut product. Review the official [repository](https://github.com/0xsline/OpenChatCut) and [website](https://openchatcut.com/) before deployment.
