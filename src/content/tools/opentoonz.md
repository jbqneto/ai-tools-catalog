## Overview

[OpenToonz](https://github.com/opentoonz/opentoonz) is a production-oriented desktop tool for traditional 2D animation. It is published by DWANGO and evolved from Toonz, including a version historically customized by Studio Ghibli.

**Good fit:** more elaborate 2D cartoons, layered animation projects, and traditional animation pipelines that require scene assembly and precise manual control.

**Trade-off:** Compared with lightweight applications such as Pencil2D, OpenToonz has a larger production feature set and a steeper workflow. Its functionality does not depend on AI.

**License:** The primary project uses a modified BSD-style license; third-party code and bundled brush resources may have separate terms. For safe downloads, use only [the official website](https://opentoonz.github.io/e/index.html) or the upstream GitHub repository, as advised by the maintainers.

**Source:** [Official source repository](https://github.com/opentoonz/opentoonz).
