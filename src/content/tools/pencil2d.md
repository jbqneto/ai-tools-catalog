## Overview

[Pencil2D](https://github.com/pencil2d/pencil) is a lightweight drawing and traditional animation editor for hand-drawn frame-by-frame work. It supports bitmap and vector drawing, letting artists create simple animations without a complex production suite.

**Good fit:** 2D cartoons, hand-drawn animation exercises, rough animatics, and testing short loops before integrating them into longer videos.

**Trade-off:** It is a manually operated animation application, not an AI agent skill or automated character animation generator. Producing smooth motion still requires careful frame sequencing and visual review.
