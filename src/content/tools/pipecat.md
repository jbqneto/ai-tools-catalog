## Overview

Pipecat is a composable framework for conversational voice and multimodal applications. It connects streaming speech recognition, language models, text-to-speech, media transport, and application logic. It supports web and mobile clients and multiple deployment patterns.

**Typical uses:** interactive voice assistants, guided customer-service calls, conversational interfaces, and multi-agent voice applications.

**Limitations:** The framework does not eliminate model, speech, telephony, or hosting costs. Latency, accuracy, and privacy depend on the services and transports chosen. Review current [documentation](https://docs.pipecat.ai) and provider terms before handling user recordings.

**Source:** [Official project repository](https://github.com/pipecat-ai/pipecat).
