## Overview

RAGFlow combines document ingestion, parsing, retrieval, and agent-oriented workflows to build knowledge-assisted AI systems. It supports multiple document formats and provides interfaces for managing knowledge bases and generating grounded answers.

**Typical uses:** document question answering, internal search, policy/manual assistants, and structured enterprise knowledge workflows.

**Limitations:** Document quality, retrieval settings, model choice, and infrastructure affect results; source citations do not guarantee factual correctness. Self-hosting requires storage, compute, and careful control of access to private documents. See the [official documentation](https://ragflow.io/docs/dev/).

**Source:** [Official project repository](https://github.com/infiniflow/ragflow).
