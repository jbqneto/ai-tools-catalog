## Overview

RAGFlow provides document ingestion, parsing, indexing, retrieval, and answer generation for knowledge-oriented AI systems. It includes a web interface and configurable agent and retrieval workflows. Source citations can help users inspect the evidence behind generated answers.

## Useful for

- Question answering over internal documentation and knowledge bases.
- Testing document-parsing and retrieval configurations.
- Building source-grounded AI applications.

## Licensing and limitations

**Apache-2.0**, according to the official repository. Self-hosting requires infrastructure, storage, and properly configured embedding/LLM services, which may incur costs. Source citations **do not guarantee answer correctness**. Review access controls, sensitive documents, retrieval quality, and model data handling before production use.
