## Overview

reanimate analyzes reference motion from websites, recordings, GIFs, and video, then guides a coding agent through reconstructing the timing and easing using tools already available in a project. It records a reference and its implementation for side-by-side visual comparison.

**Typical uses:** learning from animation patterns, reconstructing authorized motion designs, and improving consistency in web motion graphics.

**Limitations:** It is a **skill and development workflow**, not a general video editor. The documented setup requires Bun, browser tooling, and FFmpeg, and has limited platform testing. Respect rights in reference designs, assets, and branding; similarity metrics are not a substitute for creative review.
