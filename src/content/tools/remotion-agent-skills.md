## Overview

The Remotion team publishes task-focused Agent Skills such as best practices, project creation, markup, captions, rendering, and Studio workflows. They provide guidance to coding agents rather than functioning as a standalone video editor.

**Use cases:** structured React video projects, render automation, subtitle workflows, and maintaining consistent Remotion coding conventions.

**Caveats:** using the skills does not replace a working Remotion installation. Review Remotion's separate licensing and project requirements before commercial use. [Official documentation](https://www.remotion.dev/docs/ai/skills).
