The Skill Creator lives in Anthropic's public skills repository under `skills/skill-creator/`. It helps draft reusable skills, improve trigger descriptions, and evaluate them with example tasks. It is not specifically a video editor, but can help define a custom video-production skill. The overarching repository contains materials with differing licenses; verify the applicable license of the specific component.
