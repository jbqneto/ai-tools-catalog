## Overview

[Skills for Real Engineers](https://github.com/mattpocock/skills) is a collection of practical agent skills maintained by Matt Pocock. It is designed to help developers retain control over the software engineering process by introducing smaller, adaptable skills rather than an all-in-one autonomous workflow.

The repository documents installation methods for Claude Code, Codex, GitHub Copilot, Gemini CLI, and other skills-compatible agents.

## Common uses

- Clarify work requirements and planning before implementation.
- Review and triage development tasks.
- Compose reusable engineering practices into agent-assisted workflows.
- Adopt individual skills without switching to a full process framework.

## Installation

For Claude Code, the repository documents:

```text
claude plugin install mattpocock-skills@claude-plugins-official
```

For other agents, check the project's README and its `skills.sh` installation guidance. Avoid installing the same skill set through multiple methods in one agent environment, since that may create duplicates.
