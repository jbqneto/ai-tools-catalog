## What it does

[Smithery](https://www.smithery.ai/) helps developers discover MCP servers, connect agents to external services, and manage connection authorization. Its platform includes a server directory and a CLI to discover and call tools. It describes a connect-once model for reusing supported service connections across multiple agent environments.

## Useful for

- Discovering MCP servers and agent integrations.
- Configuring connections for workflows that need external services.
- Testing tool discovery and invocation from the terminal.
- Publishing MCP tools for other agent developers.

## Repository and limitations

The linked [Smithery CLI repository](https://github.com/smithery-ai/cli) is a component of the platform, **not the source code for the entire hosted service**. Smithery is a third-party provider; plans, access conditions, and the handling of linked accounts are governed by its own terms.

Review any MCP server's provenance, permissions, and privacy policy before connecting accounts. Avoid giving broad credential access to unreviewed integrations.
