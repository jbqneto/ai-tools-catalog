## Overview

Spine Animation AI guides Claude-assisted skeletal 2D animation. The repository documents positioning character artwork, creating bone hierarchies, generating idle and movement cycles, refining offsets, and previewing animations in HTML.

**Typical uses:** prototyping 2D game characters, experimenting with automated rigging, and inspecting character motion before final polish.

**Limitations:** Supplying a single character image does not guarantee production-ready separation, rigging, or motion. The repository declares **PolyForm Noncommercial 1.0.0**, so it should **not be presented as unrestricted open source or assumed safe for commercial redistribution**. Spine editor/runtime licensing and any third-party model services may impose separate conditions.
