## Overview

Stageshow is an **agent skill with a reusable React kit**, examples, and verification scripts. It helps produce staged product interface illustrations, animated cursor demonstrations, phone screens, dashboards, and marketing visuals.

The authored mockups are simulated **visual narratives**, not a browser automation system that actually performs actions in a production app.

## Useful for

- Product presentations and release announcements.
- Short UI walkthrough animations and feature cards.
- Iterating on motion and visual states with a coding agent.

The `stageshow/` source is **MIT licensed**, while example logos, photographs, product marks, and other assets may have separate rights. The official skill requires a JavaScript/React environment; filming and automated checks use additional local browser tools.
