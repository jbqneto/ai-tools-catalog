## Overview

Stageshow is part of Benji Taylor's coding-agent skill repository. It provides instructions, examples, and a reusable kit for agents to build credible product-interface illustrations, feature cards, bento layouts, and animated demonstrations in React.

**Typical uses:** marketing screenshots, app walkthrough visuals, product launch content, and agent-assisted design reviews.

**Limitations:** The result is a **mockup** unless wired to a functioning product; do not imply invented screens represent real functionality. Review the skill scripts, example assets, and each component's license. Rendering and recording still require a working development environment.

**Source:** [Official project repository](https://github.com/benjitaylor/skills).
