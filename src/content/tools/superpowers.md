Superpowers is an agent skills framework centered on structured software-development practices. Its workflow emphasizes clarifying goals, drafting a specification, creating an implementation plan, verifying changes, and reducing unnecessary complexity.

**Useful for:** repeatable engineering workflows and improving the reviewability of agent-generated code.

**Considerations:** these are process instructions, not a new model and not an automatic correctness guarantee. Review generated code and tests independently. The project has its own installation and configuration requirements.
