## Overview

Superpowers introduces a workflow for clarifying requirements, agreeing on a design, writing executable implementation plans, and verifying changes with tests and reviews. It integrates with multiple coding agents.

**Use cases:** structured software development, planning larger implementation tasks, and enforcing a review-and-test process.

**Caveats:** this is an agent workflow, not an autonomous guarantee of correct code. Test output must still be verified. Inspect included hooks and instructions and scope repository access carefully.
