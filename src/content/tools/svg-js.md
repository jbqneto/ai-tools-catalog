## Overview

[SVG.js](https://github.com/svgdotjs/svg.js) is a lightweight JavaScript library for creating and animating scalable vector graphics. It exposes a programming API to construct elements, update properties, and build interactive graphics directly in a browser.

**Good fit:** programmable illustrations, logos, charts, animated diagrams, and interactive UI graphics for websites. It can complement larger motion-graphics pipelines when SVG is an appropriate format.

**What it does not do:** SVG.js is neither an AI service nor a standalone timeline editor. Producing video files typically requires a separate capture or rendering pipeline.

**License:** MIT. Read the [official documentation](https://svgjs.dev/docs/3.0/) before implementation.

**Source:** [Official source repository](https://github.com/svgdotjs/svg.js).
