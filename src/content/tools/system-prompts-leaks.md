## Overview

This repository curates purported, extracted, and publicly discussed system prompts and related agent instructions from a range of AI services. It can be useful for understanding instruction architecture, tool descriptions, and differences between assistant products.

**Typical uses:** prompt engineering research, comparative reading, and studying agent instruction formats.

**Limitations:** **Authenticity, completeness, freshness, and redistribution rights vary by file.** Do not assume a copied prompt is official or represents a service's current behavior. The collection is not an invitation to circumvent access controls, obtain confidential system information, or reproduce proprietary assets.

**Source:** [Official project repository](https://github.com/asgeirtj/system_prompts_leaks).
