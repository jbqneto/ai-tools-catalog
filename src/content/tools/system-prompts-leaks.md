## Overview

System Prompts Leaks is a community-curated collection of **reported system prompts and assistant instruction materials** associated with AI products and developer tools. It is a reference repository, **not an executable AI tool, official provider documentation, or verified catalog of proprietary instructions**.

## Useful for

- Comparing publicly circulated prompt architectures and instruction patterns.
- Studying how agent configuration and tool orchestration are described.
- Researching prompt-engineering conventions and their evolution.
