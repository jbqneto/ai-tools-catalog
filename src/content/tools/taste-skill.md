## Overview

Taste Skill provides a reusable art-direction workflow for coding agents. It generates a coherent frontend plan, selects layout and typography patterns, encourages credible imagery, and inspects browser-rendered work rather than stopping at generated source code.

## Compared with other design skills

- **Taste Skill:** design direction, imagery, page construction and browser quality checks.
- **Impeccable:** focused critique and refinement of existing screens and components.
- **UI/UX Pro Max:** searchable UX patterns, palettes and design-system recommendations.

These are different upstream projects with overlapping use cases, not aliases or independent AI models.

## Setup and caveats

The upstream project documents installation via `npx skills add Leonxlnx/taste-skill` and requires Node.js 22+ plus a supported browser for its scripts. Allow external photo and font requests only when permitted, verify license attribution, and review generated output before shipping.
