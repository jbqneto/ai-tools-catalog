## Overview

Text-to-Lottie equips a coding agent with an animation workflow and preview environment for generating Lottie compositions. It encourages concrete assets, frame-rate and duration constraints, and named easing patterns so outputs can be inspected and refined.

**Typical uses:** vector motion graphics, branded animations, website micro-interactions, and Lottie assets for supported web or mobile players.

**Limitations:** This is a **repository-driven workflow using an external coding agent**, not a guaranteed free hosted text-to-video service. Lottie supports only a subset of animation effects; playback differs by platform and renderer. Inspect generated files and source-asset rights.

**Source:** [Official project repository](https://github.com/diffusionstudio/lottie).
