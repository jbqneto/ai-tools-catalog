## Overview

This collection gives coding agents structured documentation and implementation examples for Three.js, including cameras, lighting, loaders, textures, animation, post-processing, shaders, and React Three Fiber. Its version-specific notes help avoid using outdated APIs.

**Typical uses:** creating interactive 3D web scenes, visual demos, browser-based motion graphics, and reviewing generated Three.js code.

**Limitations:** These are **agent skill files, not the Three.js library itself**. The repository targets specific releases; verify its guidance against the version installed in your own project. Runtime support varies across WebGL and WebGPU browser environments.
