## Overview

UI/UX Pro Max Skill packages design-system reference data and workflow instructions for coding agents. It helps select interface patterns, palettes, font combinations, chart styles and constraints suitable for a given product.

## Distinctions

Compared with **Taste Skill**, UI/UX Pro Max emphasizes a structured design knowledge base. Compared with **Impeccable**, it is more focused on generating suitable design choices than auditing a finished component. All three can coexist, but installing all simultaneously may create redundant or conflicting instructions: choose a primary skill and use the others selectively.

The official repository documents installation through its CLI or skill-compatible agent setup. Inspect the current README and applicable tool compatibility before installing.
