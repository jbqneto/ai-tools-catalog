## Overview

Video Shotcraft helps coding agents storyboard, assemble, animate, and review product videos using real interface captures and Remotion compositions. The repository includes a gallery of motion examples and shot recipes.

**Use cases:** app showcases, release videos, software demonstrations, and product marketing.

**Caveats:** feature counts and previews change between releases. Video production still depends on input assets, rendering dependencies, appropriate music rights, and human quality review. Inspect the project's own license and current setup instructions.
