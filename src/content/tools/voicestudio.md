## Overview

VoiceStudio is an application for **local speech production**, including text-to-speech, voice design and cloning, dubbing, dictation, transcription, and long-form audio. Its documentation describes multiple speech engines and a local API/MCP interface.

## Useful for

- Testing speech synthesis without sending every request to a commercial API.
- Creating narration with local hardware and supported speech models.
- Integrating local transcription and dubbing into a media workflow.

## Licensing and limitations

The core repository declares **AGPL-3.0** and advertises separate paid offerings. Individual voice models and other components can have different licensing restrictions.

The advertised number of languages reflects a model/engine catalog, **not equivalent quality across every language**. Hardware requirements and voice quality vary. Local operation can avoid provider API fees but still entails compute and storage costs.

Only clone voices with the speaker's permission and clearly disclose synthetic speech when appropriate.
