YouTube Agent Skill is a community collection of skills focused on creator workflows. The project documents tasks including script development, title and thumbnail briefs, chapter planning, comment response drafting, and edit decision lists.

**Useful for:** creating consistent editorial checklists and reducing repetitive planning work.

**Considerations:** this is not an official YouTube or Anthropic product. The skill set produces plans and text, not proof of video performance, analytics access, or authorized channel publishing. Check each module and required permissions.
