## Overview

This skill pack supports drafting scripts, checking title–thumbnail pairings, preparing edit decision lists, reviewing provided retention exports, and identifying Shorts candidates. It documents a set of small Python helper scripts.

**Use cases:** preparing YouTube content and interpreting channel assets supplied by the creator.

**Caveats:** it does not automatically publish videos or inherently access private YouTube Analytics. Any retention or performance recommendation depends on the data provided. The project describes an MIT license.
