## Overview

[YouTube Research Skills](https://github.com/TubeLabHQ/youtube-research-skills) are task-oriented workflows built around the [TubeLab MCP](https://tubelab.net/youtube-mcp). The collection includes niche discovery, competitor research, trend analysis, scripts, titles, thumbnails and monetization research. The project defines citation and recency requirements for its reports.

## Cost and data boundaries

**Important:** the skills can be installed from their open repository, but useful data retrieval depends on the TubeLab service. The README states that searches use credits, while some reads are included. Check the current provider plan and costs before building automated research loops. This is public-market research, **not** direct access to a channel owner's private analytics.
